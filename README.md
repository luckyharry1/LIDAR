# LIDAR

A Roblox horror-maze game. You see only through a LIDAR gun that scatters glowing dots: white terrain, green friends, red enemies.

## Run it

1. Install tools: `rokit install` (pins Rojo, Lune, StyLua, Selene in `rokit.toml`).
2. `rojo serve`, then connect from Roblox Studio with the Rojo plugin.
3. Or build a place file: `rojo build -o build/LIDAR.rbxl`.
4. Run every check: `./scripts/check.sh`.

See `docs/PROGRESS.md` for status and `docs/DECISIONS.md` for design decisions.
